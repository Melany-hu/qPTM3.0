Overview

The qPTM REST API returns quantitative PTM proteomics records as JSON. It is free to use for research; no API key is required. Please cite qPTM if you use these data in a publication.

Base URL: https://qptm3.omicsbio.info/api

  • All endpoints accept GET (and CORS preflight OPTIONS).
  • Responses are application/json; charset=utf-8.
  • Errors use HTTP 400/404/500 with {"error": "message"}.
  • Clean paths such as /api/protein/P04637 require Apache rewrite; the equivalent .php query-string form always works.
  • Please keep request rates reasonable. For bulk analysis, use the dataset download.
Endpoints

Organism values: human, mouse, rat, yeast, or all. PTM types: phosphorylation, acetylation, methylation, ubiquitylation, glycosylation, sumoylation, malonylation, palmitoylation, lactylation, succinylation, crotonylation, β-hydroxybutyrylation, or all.

GET Search events

Search quantitative events (same resolution as the website: gene, UniProt, protein name, function, sample, or condition).

GET /api/search?q={keyword}
ParameterRequiredDefaultDescription
qyes—Search keyword
fieldnoanyany, gene, uniprot, protein, function, sample, condition
organismnoallOrganism filter
ptm_typenoallPTM type filter
pageno1Page number
per_pageno20Page size, maximum 100

Example: GET /api/search?q=TP53&field=gene&organism=human&per_page=5

GET Protein

PTM modifications, sites, and experimental conditions for a protein (from quantitative events). Optional position / ptm_type filters.

GET /api/protein/{uniprot_ac}

Example: GET /api/protein/P04637 or GET /api/protein.php?uniprot_ac=P04637&position=392

GET Site events

All quantitative events for one residue. Optional ptm_type. Query form: uniprot_ac and position.

GET /api/site/{uniprot_ac}/{position}

Example: GET /api/site/P04637/392

GET Conditions

Search conditions by name/keyword and/or condition type (contrast_type). Returns matching condition summaries plus their quantitative PTM events (sites, log2 ratios, p-values, experiment metadata).

GET /api/conditions?q={keyword}
ParameterRequiredDescription
qyescondition
contrast_typeyespharmacological, genetic, physical, disease, cell_state, other
organismnoOrganism filter
ptm_typenoPTM type filter
page / per_pagenoEvent pagination (max 100)

Prefer a condition keyword in q for site-level rows; a very broad contrast_type-only query returns the condition catalog only. Example: GET /api/conditions?q=UCEC

GET Browse

type must be condition or sample. For conditions, filter by condition type and/or condition ontology.

GET /api/browse/{type}
ParameterRequiredDefaultDescription
typeyes—condition or sample
organismnoallOrganism filter
ptm_typenoallPTM type filter
contrast_typeno—Condition type (only type=condition): pharmacological, genetic, physical, disease, cell_state, other
ontologyno—Condition ontology keyword (preferred name, ontology ID, agent key, or alias)
agent_keyno—Exact ontology agent key
pageno1Page number
per_pageno50Page size, maximum 200

Examples:

GET /api/browse/condition?contrast_type=pharmacological&per_page=20
GET /api/browse/condition?ontology=endometrial%20carcinoma&per_page=20
GET /api/browse/sample?organism=human&per_page=20

Code examples

Replace the base URL if you are calling a local deployment.

curl

curl -s "https://qptm3.omicsbio.info/api/search.php?q=TP53&field=gene&organism=human&per_page=5"

Python

import requests

r = requests.get(
    "https://qptm3.omicsbio.info/api/search.php",
    params={"q": "TP53", "field": "gene", "organism": "human", "per_page": 5},
    timeout=30,
)
r.raise_for_status()
print(r.json()["total"], "events")

R

library(jsonlite)
url <- "https://qptm3.omicsbio.info/api/search.php?q=TP53&field=gene&organism=human&per_page=5"
data <- fromJSON(url)
print(data$total)
