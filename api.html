Overview

The qPTM REST API returns quantitative PTM proteomics records as JSON. It is free to use for research; no API key is required. Please cite qPTM if you use these data in a publication.

Base URL: https://qptm3.omicsbio.info/api

  • All endpoints accept GET (and CORS preflight OPTIONS).
  • Responses are application/json; charset=utf-8.
  • Errors use HTTP 400/404/500 with {"error": "message"}.
  • Clean paths such as /api/protein/P04637 require Apache rewrite; the equivalent .php query-string form always works.
  • Please keep request rates reasonable. For bulk analysis, use the dataset download.
Endpoints

Organism values: human, mouse, rat, yeast, or all. PTM types: phosphorylation, acetylation, methylation, ubiquitylation, glycosylation, sumoylation, or all.

GET Search events

Search quantitative events (same resolution as the website: gene, UniProt, protein name, function, sample, or condition).

GET /api/search?q={keyword}
ParameterRequiredDefaultDescription
qyes—Search keyword
fieldnoanyany, gene, uniprot, protein, function, sample, condition
organismnoallOrganism filter
ptm_typenoallPTM type filter
pageno1Page number
per_pageno20Page size, maximum 100

Example: GET /api/search?q=TP53&field=gene&organism=human&per_page=5

GET Protein

Protein annotation and aggregated PTM sites.

GET /api/protein/{uniprot_ac}

Example: GET /api/protein/P04637

GET Site events

All quantitative events for one residue. Optional ptm_type. Query form: uniprot_ac and position.

GET /api/site/{uniprot_ac}/{position}

Example: GET /api/site/P04637/15

GET Conditions

Distinct experimental conditions for a protein or site, with event counts and log2 ratio range.

GET /api/conditions?uniprot_ac={ac}
ParameterRequiredDescription
uniprot_acyesUniProt accession
positionnoResidue position
ptm_typenoPTM type filter

Example: GET /api/conditions?uniprot_ac=P04637&position=15

GET Kinases / enzymes

Experimental and predicted kinases (phosphorylation) or acetyltransferases (acetylation) for a site. Query form: uniprot_ac and position.

GET /api/kinases/{uniprot_ac}/{position}

Example: GET /api/kinases/P04637/15

GET Browse

type must be gene, condition, or sample.

GET /api/browse/{type}
ParameterRequiredDefaultDescription
typeyes—Path segment or query parameter
organismnoallOrganism filter
ptm_typenoallPTM type filter
letternoallFirst letter A–Z
pageno1Page number
per_pageno50Page size, maximum 200

Example: GET /api/browse/gene?organism=human&letter=T&per_page=20

Event response fields

Search and site endpoints return event objects with these fields:

FieldTypeDescription
pmidstringPubMed ID of the source study
uniprot_acstringUniProt accession
genestringGene symbol
positionintegerModified residue position
ptm_typestringModification type (lowercase)
sequence_windowstringPeptide / sequence window
samplestringSample description
conditionstringExperimental condition
organismstringOrganism
log2_rationumberPTM log2 quantification ratio
p_valuenumberPTM p-value
proteome_log2_rationumberMatched proteome log2 ratio, if available
proteome_p_valuenumberMatched proteome p-value

fdr_flagbooleanWhether an FDR value is present
Code examples

Replace the base URL if you are calling a local deployment.

curl

curl -s "https://qptm3.omicsbio.info/api/search.php?q=TP53&field=gene&per_page=5"

Python

import requests

r = requests.get(
    "https://qptm3.omicsbio.info/api/search.php",
    params={"q": "TP53", "field": "gene", "per_page": 5},
    timeout=30,
)
r.raise_for_status()
print(r.json()["total"], "events")

R

library(jsonlite)
url <- "https://qptm3.omicsbio.info/api/search.php?q=TP53&field=gene&per_page=5"
data <- fromJSON(url)
print(data$total)
