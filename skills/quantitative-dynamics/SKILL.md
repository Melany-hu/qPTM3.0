# Quantitative PTM dynamics

## Tool order
1. `qptm_site_conditions` — fold-changes per condition for a specific site.
2. `qptm_search` — discover sites and events by gene/condition.
3. `ekpi_quantitative` — kinase–substrate quantitative matrices.
4. `cancerproteome_disease` — cancer vs normal if disease context.

## Presentation
- Use tables: Condition | log2FC | significance | Source.
- Mention time points and treatments when present in data.
