# Kinase–substrate investigation

## Tool order
1. `qptm_kinases` — integrated experimental + predicted for the site.
2. `psp_kinase_substrate` — curated kinase–substrate.
3. `iptmnet_enzymes` — enzyme network context.
4. `gps6_kinases` — predicted specificity (**label as predicted**).
5. `ekpi_kinases` / `ekpi_quantitative` — quantitative KPS if site known.

## Synthesis tips
- List kinases with evidence type per source.
- Note consensus kinases across ≥2 experimental sources.
- If only GPS predicts a kinase, say "predicted, not curated experimental."
